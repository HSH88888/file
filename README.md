# 📷 사진 정리 도우미

600GB가 넘는 사진 폴더에서 **완전히 같은 중복 파일**을 찾아 직접 골라서 지우고,
모든 사진을 **촬영 날짜·크기별로 둘러볼 수 있는** 프로그램입니다.
내 컴퓨터 안에서만 동작하며(`http://127.0.0.1:8765`), 사진이 외부로 전송되지 않습니다.

## 실행 방법 1 — exe 파일 (Python 설치 필요 없음, 가장 쉬움)

1. 이 저장소의 **Actions** 탭 → **Windows 실행 파일 빌드** → 가장 위의 초록색 ✓ 실행을 누릅니다.
2. 아래쪽 **Artifacts** 의 **PhotoDedup-windows** 를 눌러 받고 압축을 풉니다.
3. **`PhotoDedup.exe`** 를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**. (서명되지 않은 프로그램이라 나오는 경고입니다)
4. 브라우저가 열리면 **📁 폴더 선택…** 으로 사진 폴더를 고르고 **스캔 시작**.
   - 검은 창이 프로그램 본체입니다. 다 쓰고 나서 닫으세요.
   - 분석 결과·삭제 기록은 `%LOCALAPPDATA%\PhotoDedup` 에 저장됩니다.

코드를 고쳐서 올리면 exe 도 자동으로 다시 만들어집니다.

## 실행 방법 2 — Python 으로 실행 (Windows)

1. [Python](https://www.python.org/downloads/) 설치 (설치 화면에서 **Add python.exe to PATH** 체크)
2. 이 저장소를 내려받아 압축을 풉니다.
3. **`사진정리_실행.bat`** 을 더블클릭합니다.
   - 처음 실행 시 썸네일·휴지통 기능용 패키지(Pillow, pillow-heif, send2trash)를 자동 설치합니다.
4. 브라우저가 열리면 사진 폴더 경로(예: `D:\사진`)를 입력하고 **스캔 시작**.
   - 여러 폴더(예: `D:\사진`, `E:\백업`)를 한 줄에 하나씩 넣으면 폴더끼리도 중복을 찾습니다.

명령줄에서 바로 실행할 수도 있습니다.

```
python photo_dedup.py "D:\사진"
python photo_dedup.py "D:\사진" "E:\백업"     # 여러 폴더 비교
python photo_dedup.py --no-scan "D:\사진"      # 지난 결과만 다시 보기
```

macOS / Linux 에서도 `python3 photo_dedup.py ~/Pictures` 로 동작합니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 🔁 중복 파일 | 같은 사진끼리 묶어서 보여줌. 정리 시 확보 용량이 큰 순으로 정렬. 썸네일·경로·촬영일 확인 후 지울 파일 체크 |
| 🗂️ 전체 파일 | 전체 사진을 촬영일·크기·이름·경로 순으로 정렬. 연도/월/크기/확장자/중복 여부로 필터, 썸네일·목록 보기 |
| 📊 날짜·크기 통계 | 연도별·월별·크기별·확장자별 개수와 용량, 중복이 많은 폴더. 행을 누르면 해당 사진 목록으로 이동 |

사진을 누르면 크게 보기(←/→ 키로 이동), **📂 폴더** 버튼은 탐색기에서 해당 파일을 선택해 엽니다.

## 중복 판단 방식 (빠르면서 정확하게)

1. 폴더 전체 탐색 → 파일 크기 수집
2. 사진 속 촬영정보(EXIF) → 없으면 파일 이름의 날짜(`20230512_...`) → 없으면 수정 날짜 순으로 날짜 결정
3. **크기가 같은 파일만** 앞·뒤 64KB를 비교
4. 그래도 같은 후보만 **파일 전체 내용을 해시(BLAKE2b)로 비교** → 바이트 단위로 같아야 중복

크기가 다르면 읽지 않으므로 600GB라도 실제로 끝까지 읽는 양은 중복 후보뿐입니다.
결과는 `.photo_dedup/` 폴더에 저장되어, 다시 스캔하면 바뀐 파일만 새로 분석합니다.

> 이름이 달라도 내용이 같으면 중복으로 찾습니다. 반대로 해상도를 줄였거나 편집한 사진은 내용이 달라서 중복으로 보지 않습니다.

## 삭제와 안전장치

- **자동 선택**: 그룹마다 1개만 남기고 나머지를 *선택만* 합니다
  (가장 먼저 만든 파일 / 경로가 짧은 파일 등 규칙, "꼭 남길 폴더" · "먼저 지울 폴더" 지정 가능).
  실제 삭제는 확인 후 하단의 **선택한 파일 삭제** 버튼을 눌러야 합니다.
- 삭제 방식: **휴지통** (기본, 권장) / **`<폴더명>_중복삭제대기` 폴더로 이동** / 영구 삭제(확인 문구 입력 필요)
- 같은 그룹의 **모든 사본은 절대 지우지 않습니다** — 화면과 서버 양쪽에서 막고,
  삭제 직전에 남길 파일이 디스크에 실제로 있는지 다시 확인합니다.
- 스캔 후 파일이 바뀌었으면(크기 다름/없음) 건너뜁니다.
- 모든 삭제 내역은 `.photo_dedup/delete_log.csv` 에 기록됩니다 (원래 경로, 이동 경로, 남긴 파일).

## 지원 형식

사진(jpg, png, heic, webp, gif, bmp, tiff…), RAW(cr2, cr3, nef, arw, dng, orf, rw2, raf…),
동영상(mp4, mov, avi, mkv, mts…). 다른 파일까지 보려면 "모든 파일 포함"을 체크하거나 `--all-files`.
